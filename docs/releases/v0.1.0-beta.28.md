## What changed since v0.1.0-beta.27

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.28` lists the fixes
(PR #256): System → AltMount reads AltMount's empty list of streams as
"nothing plays", and the AltMount image installed with Media Manager now
mounts its drive in the folder Cosmos creates. Searches, downloads, language
and quality rules are unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:cd5081d2f72a235832e15fc0799be010baf1fc276b7b7fdb3dae79c44cd7c0fe
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:b565f33ffbd6d3587f32e0416786d6c71f9385811a20f80c9a25e887c3f52729
MEDIA_MANAGER_VERSION=0.1.0-beta.28
MEDIA_MANAGER_COMMIT=f219944588c8e3ab717ea172cca19a529bc8bc91
```

Upgrading from `v0.1.0-beta.27` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.27` image pair on the same database.
