## What changed since v0.1.0-beta.22

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.23` lists the changes
(PRs #240 to #245). Unused code, the unreachable search capability profiles and
planner (migration 0070) and two dated status logs are removed; a backup whose
restore check was interrupted by a restart now recovers on the next attempt;
and superseded, finished work-queue events older than a week are removed
hourly. Search requests, pacing, quotas, language and quality rules are
unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:3d1a0c945a4de4ca47421ac77bd773f4311a44cb4b92f2f28e61ca0ea086e9ef
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:36adbea8a1acfad14a95af5f719a7bbc8b0f2c3f91d83293a6943d54de7dc103
MEDIA_MANAGER_VERSION=0.1.0-beta.23
MEDIA_MANAGER_COMMIT=adb784457bfc77def080ec8b21a5cc9e135159fe
```

Upgrading from `v0.1.0-beta.22` runs migration 0070, which drops the
unused `indexer_capability_profiles` and `indexer_operation_status` tables and
their trigger functions. It refuses to run if a profile was ever activated or
an operation status was recorded. Create an encrypted backup first as usual.
The `v0.1.0-beta.22` code expects schema 69 and reports not ready on schema
70, so a rollback restores that backup before starting the `v0.1.0-beta.22`
image pair.
