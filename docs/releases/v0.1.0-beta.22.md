## What changed since v0.1.0-beta.21

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.22` lists the changes
(PRs #237 and #238), a cleanup release: stale documentation and an unused
AltMount client path are removed, and the never-used indexer commissioning v2
(routes, setting, tables and pacing gate) is removed with migration 0069.
Search, pacing, quotas, language and quality rules are unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:1bc1c341512d7e91da876a87f1f8eff67d29d923f37de27520d8cf2209388617
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:1553a8373ae781852ad16b18ef3fc27f6bd60ab14956459467fe579af0cfaf6b
MEDIA_MANAGER_VERSION=0.1.0-beta.22
MEDIA_MANAGER_COMMIT=d4d56bd60534ab4556a3d051f0042e0fa27ae982
```

Upgrading from `v0.1.0-beta.21` runs migration 0069, which drops the
unused commissioning v2 run and step tables and the gate column on
`indexer_budget_state`. It refuses to run if any v2 history exists. Create an
encrypted backup first as usual. The `v0.1.0-beta.21` code expects schema 68
and reports not ready on schema 69, so a rollback restores that backup before
starting the `v0.1.0-beta.21` image pair.
