## What changed since v0.1.0-beta.6

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.7` lists every change
(PRs #183, #184 and #185): **Slet** for quality profiles, with a move of the
titles to another profile when the profile is in use; **Slet** for library
folders, connections and indexers that nothing uses; **Omdøb** for library
folders; a tidier title page; titles named in the activity list; small
tidy-ups across the website; and lists that no longer wait for PostgreSQL JIT.

The rules for checking language and quality did not change, and files are
still measured after download. Deleting a profile that is in use moves its
titles to a profile the owner picks, so those titles then follow that
profile's requirements; waiting titles are not searched under them until the
owner presses **Brug på ventende**. No delete touches a file or folder on disk.

both. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.6` image pair.

## Verification

- **CI:** the runs in the identity table.
- **Production:** the owner's library runs this commit (schema 57). The API
  answered ready after the deploy, the live API description lists the new
  delete routes, and the list endpoints answered in 50 to 80 ms where they
  took about 2.4 s before.
- **Security:** zero open Dependabot alerts and `npm audit --omit=dev` reports
  zero vulnerabilities at tagging time.

## Known limitations

- `linux/amd64` only; ARM64 is not built.
- Deleting, and moving titles to another profile, were verified with automated
  tests against a real PostgreSQL and in browser tests. Nothing was deleted on
  the production library at tagging time.
- A library folder, connection or indexer that has been used cannot be
  deleted, only switched off.
- **Fejllog** shows failures stored in the database, not the server's own
  process log.
- A Danish name does not count as proof of Danish audio. A DANiSH release with
  untagged audio is rejected in libraries that require Danish audio.
- Danish releases that do not state Danish in the name and have no series ID
  are still held.
- **Overtag bibliotek** and resuming an interrupted **Flyt** are covered by
  automated tests but have not been used on real titles.
- No installation on a genuinely clean third-party host has been recorded.
- Off-site backup is not built in.
- Restore is documented and operator-run, not automated.
- The web UI is Danish only.
- Only the supported stack (Seerr, Media Manager, Newznab, AltMount, Plex) is
  tested.
