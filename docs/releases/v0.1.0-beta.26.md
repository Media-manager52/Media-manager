## What changed since v0.1.0-beta.25

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.26` lists the change
(PR #251): the Cosmos install can install AltMount together with Media Manager
(on by default), and Media Manager connects to it on its first start. A new
install then only needs the news-server login under Usenet-servere. Existing
installs and searches, downloads, language and quality rules are unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:ed27ee976298253bd7891cb25be1ff474ea39d2dd1ccb18bc7027e0a5883cd74
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:6a39e34402fc5628638485925ebb32f3223de4847caa85f10de7c1bb8a04ad8c
MEDIA_MANAGER_VERSION=0.1.0-beta.26
MEDIA_MANAGER_COMMIT=34397c48364f5387b761411ff90d9e796c19fb0f
```

Upgrading from `v0.1.0-beta.25` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.25` image pair on the same database.
