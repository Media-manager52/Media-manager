## What changed since v0.1.0-beta.2

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.3` lists every change
(PRs #133-#168). In short:

- **Log ind med Plex** and **Brug anbefalet opsætning**, a shorter Cosmos
  install form, a generated backup key and a list of known indexers.
- Title search through TMDB without Seerr.
- **Flyt**, **Slet**, **Hent**, **Tilføj sæson**, **Erstat dårlig fil**, a
  recycle bin and quality profile editing on the website.
- A plain-language explanation of a title's status.
- 1080p and 4K folders in one Plex library, and a guided **Overtag bibliotek**.
- A stored plan that resumes an interrupted title move (migration 56), and
  backups in their own worker lane.
- The time of the last connection check (migration 57), and a backup whose
  file was deleted no longer shows as checked.
- Stricter language evidence, NFO checks before download and the next good
  release after a failed download.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:15cc6381bcf68a0244ed40acb34d709266521b5987e2da0980ffb2407b685f94
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:0075d0d9bc5f06909b8b907025eeb2d187a0d27db20c975e830e467cdd1a64f8
MEDIA_MANAGER_VERSION=0.1.0-beta.3
MEDIA_MANAGER_COMMIT=c11b8997c7cf40bc5fdb4518fb1dc75a542b80a7
```

Upgrading from `v0.1.0-beta.2` migrates schema 55 to 57 at API start. Create an
encrypted backup first. A rollback restores the pre-upgrade database into a
fresh database and starts the `v0.1.0-beta.2` image pair; never run an older
image against a newer schema.

## Known limitations

- `linux/amd64` only; ARM64 is not built.
- **Overtag bibliotek** and resuming an interrupted **Flyt** are covered by
  automated tests but have not been used on real titles.
- No installation on a genuinely clean third-party host has been recorded.
- Off-site backup is not built in.
- Restore is documented and operator-run, not automated.
- The web UI is Danish only.
- Only the supported stack (Seerr, Media Manager, Newznab, AltMount, Plex) is
  tested.
