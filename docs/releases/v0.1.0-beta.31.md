## What changed since v0.1.0-beta.30

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.31` lists the change
(PR #262): System → AltMount shows which AltMount runs, and a normal AltMount
can switch to Media Manager's build through Cosmos, keeping its settings,
database, files and drive. Searches, downloads, language and quality rules are
unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:91a1ea3b1a0c54f8df9937ec9a8cf2a5116f9c032b936b7cd0bc0af51acf61f4
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:b35761d7b9747aa88206ab52c604b3345703d2e2d0130a2707d4d3e57784376c
MEDIA_MANAGER_VERSION=0.1.0-beta.31
MEDIA_MANAGER_COMMIT=a6a8c4e37088d0a80b0aee3139cc41a27936dd81
```

Upgrading from `v0.1.0-beta.30` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.30` image pair on the same database.
