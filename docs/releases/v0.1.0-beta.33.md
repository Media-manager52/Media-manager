## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:66aa9d848e4eb52aadeac6242cf91eea5b50606f0b685055fd6692bf99d53972
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:f3418bb36731eda75af54b141f0d8584c4d2256a3c11ff58eb66f003a5ed3daa
MEDIA_MANAGER_VERSION=0.1.0-beta.33
MEDIA_MANAGER_COMMIT=e9c9b3b2445699d8e58697f08aa6969c1d41275a
```

Upgrading from `v0.1.0-beta.32` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.32` image pair on the same database.
