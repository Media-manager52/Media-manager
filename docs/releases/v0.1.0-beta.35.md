## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:495ab393248287315e13ec65d92c7bfd2b98b0087f27eebe5532e5c34bf57847
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:6fbf66d2a950dd839e705ca3337d6a4cc50abab9941656d21163f5cef16049f1
MEDIA_MANAGER_VERSION=0.1.0-beta.35
MEDIA_MANAGER_COMMIT=b3a6180449661979d6e8d750023481bda4fc0419
```

Upgrading from `v0.1.0-beta.34` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.34` image pair on the same database.
