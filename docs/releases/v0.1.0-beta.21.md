## What changed since v0.1.0-beta.20

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.21` lists the changes
(PRs #234, #233 and #235), defects found by DeepSeek V4.1 Flash and Codex
reviews and verified against the code: connection checks never resolve server
secrets, a Prowlarr upload hides the indexer keys, support-text redaction is
safe with any characters, stuck handlers are moved behind healthy work, backup
downloads get a long write window, running work is not shown as retrying, the
title page gets each workflow's root, profile and actions, a cancelled
duplicate pack no longer hides the active one, the calendar asks for the right
range, and a required resolution is checked on the measured file.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:10701759b92b59eebea9becb232b8e3b3c8393e4a5bd1cf237427b619ebbafa9
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:e3333a1978c6e949742a37e447f068d7718f2d1105d174781d4b458aec6ff17f
MEDIA_MANAGER_VERSION=0.1.0-beta.21
MEDIA_MANAGER_COMMIT=54197c6ccc63903c90ad40e47310b458d0181df9
```

Upgrading from `v0.1.0-beta.19` runs migration 0068, which lets the indexer
endpoint fingerprint accept a key saved on the website. No data is rewritten.
Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.19` image pair; the older code ignores the widened function.
