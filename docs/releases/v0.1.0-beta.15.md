## What changed since v0.1.0-beta.14

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.15` lists the change
(PR #221): fourteen new Go tests written with OpenAI Codex in an isolated
container and reviewed before merging (list intake, AltMount upload, indexer
pacing, Plex confirmation identities, subtitle policy), and one fix they
exposed: MDBList TVDB ids and release years are read only when the whole value
is a positive whole number, so a malformed value can no longer match an
unrelated title. Language and quality requirements are unchanged.
