## What changed since v0.1.0-beta.24

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.25` lists the change
(PR #249): a new settings page, Usenet-servere, lists, adds, changes, reorders,
turns off and removes AltMount's Usenet servers and tests a login before it is
saved. Passwords go to AltMount only. Searches, downloads, language and quality
rules are unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:07168c56859f334de31f619af9784b8a731e99dd23ef03c91a0128d27c45a3f9
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:095be5659df7501b1affbfb071f5895698b9d3cc64fcf1de58aec189753e2a28
MEDIA_MANAGER_VERSION=0.1.0-beta.25
MEDIA_MANAGER_COMMIT=ff490484a89a16b2e111e30b6e38d2ea4e3f301e
```

Upgrading from `v0.1.0-beta.24` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.24` image pair on the same database.
