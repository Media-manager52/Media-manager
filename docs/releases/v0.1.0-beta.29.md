## What changed since v0.1.0-beta.28

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.29` lists the change
(PR #258): "Ret Plex" gives Plex AltMount's drive and Media Manager's library
folders through Cosmos, and the recommended setup tries every folder of a Plex
library. Searches, downloads, language and quality rules are unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:3001e251045cb801ccc10a59b9eca0219b5dac3fbbfb6f85738e1c42a86efd26
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:4530c7ece654a22242753944318ba9d00092418d249284ef3be1665a8feded05
MEDIA_MANAGER_VERSION=0.1.0-beta.29
MEDIA_MANAGER_COMMIT=89af0bfdc24c9be28d5b1aef281b9a754ce56d19
```

Upgrading from `v0.1.0-beta.28` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.28` image pair on the same database.
