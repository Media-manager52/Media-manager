## What changed since v0.1.0-beta.29

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.30` lists the change
(PR #259): the Cosmos install can add Plex too, Brug anbefalet opsætning creates
a missing Plex library, and folders Cosmos creates belong to the media user.
Searches, downloads, language and quality rules are unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:dd96d6b411b2b26895a08ac63714841dee3870bbca3c9c48e24dbefa94f2e59a
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:9735027a05072e3d4ac325ad7f98d8f41c82830fceec6ed3b2b04281f194adcf
MEDIA_MANAGER_VERSION=0.1.0-beta.30
MEDIA_MANAGER_COMMIT=73b55dee474ff30afcc8d144e5356836de04c8ed
```

Upgrading from `v0.1.0-beta.29` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.29` image pair on the same database.
