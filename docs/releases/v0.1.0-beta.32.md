## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:1775f35a908e6d0b6a5b0a0add447091d33749f0f31b64122adc44b68d22d884
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:0860baf4ae76ca26055b07166ea36b6650dcdba578e1a51c7b36eb00ccd81ed2
MEDIA_MANAGER_VERSION=0.1.0-beta.32
MEDIA_MANAGER_COMMIT=a664138490a61117ae53a4dd52e011fc59738114
```

Upgrading from `v0.1.0-beta.31` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.31` image pair on the same database.
