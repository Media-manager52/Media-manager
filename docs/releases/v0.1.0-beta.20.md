## What changed since v0.1.0-beta.19

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.20` lists the changes
(PR #230), defects found by a DeepSeek V4.1 Flash review of the library,
integration and intake areas and verified against the code: subtitle links are
recycled with their video, archive and move wait for Plex confirmation, a
wrong-kind move is refused before planning, the import scan skips the recycle
bin, website-saved indexer keys get an endpoint fingerprint (schema 68),
recommended setup never defaults a 4K-only folder, a seasonless Seerr series
request asks the owner, and IMDb CSV files may carry a byte order mark.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:3bf1daec0f5836405986cd0c30171f6432dd1b787ffbd01d6a43ada38adc4804
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:0afbd27698924f38d75aa746adccc544d200551846530e74b88da2e8b9741609
MEDIA_MANAGER_VERSION=0.1.0-beta.20
MEDIA_MANAGER_COMMIT=814f5c8d88f1bed664c41840d3e7d0b1a031dafc
```

Upgrading from `v0.1.0-beta.19` runs migration 0068, which lets the indexer
endpoint fingerprint accept a key saved on the website. No data is rewritten.
Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.19` image pair; the older code ignores the widened function.
