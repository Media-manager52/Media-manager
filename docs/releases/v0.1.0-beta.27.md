## What changed since v0.1.0-beta.26

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.27` lists the change
(PR #254): a new page, System → AltMount, shows AltMount's drive, Usenet
servers with quota and what is played now, and system status warns when Plex
cannot see AltMount's files. Searches, downloads, language and quality rules
are unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:8b9d0ff0a221461d2476a6db6edfffb97eaea2049f70feb0f24a50f8b52108ef
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:9ab1df284d8cd087b1f918c61a00e081fb970b2a67ccc45321bb34ebdb8f99a7
MEDIA_MANAGER_VERSION=0.1.0-beta.27
MEDIA_MANAGER_COMMIT=af5f7e5d53fd61d5895d05bc8bfe33a6b8772d90
```

Upgrading from `v0.1.0-beta.26` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.26` image pair on the same database.
