## Changes

See [CHANGELOG.md](../../CHANGELOG.md), section `0.1.0-beta.37`, and [PR #274](https://github.com/Media-manager52/Media-manager/pull/274).

Partial provider answers retain each counter's age and paired ceiling; actual recovery probes are durably spaced. Verified sources lost before publication planning enter the existing guarded repair path. Concurrent Usenet changes preserve an enabled server. Off-site requests reject redirects. Queue timings exclude old events and report median/p90. Kilder reports enforced quotas; Henter nu pages through one combined state filter. Language and quality requirements, bounded inspection and exact Plex confirmation remain enforced.

## Installation and upgrade

Use [the install guide](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:b2d1b7949b93bdfe1ad124e65e03202bebc20e51dcdc919bdf9f4892e2132000
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:306033684896819699a45fde30e9d32144aa45aacfc03543e8d856321879c7f2
MEDIA_MANAGER_VERSION=0.1.0-beta.37
MEDIA_MANAGER_COMMIT=fe4942ec31b45eda4c10fa46452fe1cd29ca6ea6
```

From beta.36, migration 0072 adds independent provider counter/ceiling observation times, paired ceilings and last-probe times. Existing readings and recent recovery requests are carried forward. No media or observations are deleted. Create and verify an encrypted backup before upgrading. Rollback requires the beta.36 image pair and a database restored from the pre-upgrade backup; schema-71 binaries do not report ready on schema 72.

## Verification and limitations

- Local Go vet and all 46 packages with tests passed with `-race`, including disposable PostgreSQL integration tests.
- Frontend lint/typecheck/build, 197 unit tests and 327 mocked browser tests passed; 3 browser tests were skipped by the existing configuration.
- Pinned staticcheck/govulncheck, documentation checks and 56 CI-script tests passed.
- Regression tests cover partial/expired counters, simultaneous and migrated probes, unverified/superseded imports, concurrent Usenet changes, redirected uploads, queue cohorts and pagination past 200 workflows.
- No live indexer calls, downloads, media scans or production deployment form part of this release verification. Other limitations remain as listed for [beta.11](v0.1.0-beta.11.md#known-limitations).
