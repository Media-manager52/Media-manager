## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:5145913136a7fbefa6da4a2c0a44b963fc190e2be6051e0eee5557d7f36d7770
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:65b73819e10e59c0f6ce94e00695b733c877138dcbf29b68c444fbb1277f6bb1
MEDIA_MANAGER_VERSION=0.1.0-beta.34
MEDIA_MANAGER_COMMIT=d4a8bb5aa0b10506964790a5070e088e5d184013
```

Upgrading from `v0.1.0-beta.33` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.33` image pair on the same database.
