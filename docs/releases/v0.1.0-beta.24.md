## What changed since v0.1.0-beta.23

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.24` lists the changes
(PR #247). Untouched Blu-ray and DVD disc releases are rejected before
download; the work list is planned per query so it no longer times out; and a
movie release without a playable video file is reported as
`no_playable_media`. Search requests, pacing, quotas, language and quality
rules are otherwise unchanged.

## Installation and upgrade

Use [../operations/install-release.md](../operations/install-release.md) with:

```sh
MEDIA_MANAGER_API_IMAGE=ghcr.io/media-manager52/media-manager-api@sha256:c190be72df782445f46ed3826320ba828fb6888a59496aa5fd3c36df09184b75
MEDIA_MANAGER_UI_IMAGE=ghcr.io/media-manager52/media-manager-ui@sha256:3f485011fd393721a10e25016cc297de332123d43c4f4f10dddbf215a68825c7
MEDIA_MANAGER_VERSION=0.1.0-beta.24
MEDIA_MANAGER_COMMIT=f7e31942473ba8ddabd1fc61cb5a96ddbff28584
```

Upgrading from `v0.1.0-beta.23` needs no migration: the database stays at
schema 70. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.23` image pair on the same database.
