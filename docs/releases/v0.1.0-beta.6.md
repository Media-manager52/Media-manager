## What changed since v0.1.0-beta.5

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.6` lists every change
(PR #181): a row of recently added titles, a search field in the menu, sorting
and a folder filter in the library, one button for a group of cases, verified
downloads per indexer and posters in the calendar. The server changes are
read-only. No language or quality requirement changed, and files are still
measured after download.

both. Create an encrypted backup first as usual. A rollback starts the
`v0.1.0-beta.5` image pair.

- **Security:** zero open Dependabot alerts and `npm audit --omit=dev` reports

## Known limitations

- `linux/amd64` only; ARM64 is not built.
- The group button under Kræver handling covers the cases that share an
  action. Individual cases cannot be picked. It was verified with automated
  tests and was not pressed on the production library at tagging time.
- The download numbers on Kilder count finished downloads only.
- **Fejllog** shows failures stored in the database, not the server's own
  process log.
- A Danish name does not count as proof of Danish audio. A DANiSH release with
  untagged audio is rejected in libraries that require Danish audio.
- Danish releases that do not state Danish in the name and have no series ID
  are still held.
- **Overtag bibliotek** and resuming an interrupted **Flyt** are covered by
  automated tests but have not been used on real titles.
- No installation on a genuinely clean third-party host has been recorded.
- Off-site backup is not built in.
- Restore is documented and operator-run, not automated.
- The web UI is Danish only.
- Only the supported stack (Seerr, Media Manager, Newznab, AltMount, Plex) is
  tested.
