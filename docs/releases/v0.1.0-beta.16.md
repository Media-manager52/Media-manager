## What changed since v0.1.0-beta.15

The [changelog](../../CHANGELOG.md) section `0.1.0-beta.16` lists the changes
(PR #223), two defects found by an OpenAI Codex review and verified against the
code: a repair now attaches only to an open workflow for the same library root
(and, for a missing-audio upgrade, the upgrade profile), so its confirmation can
no longer retire a link in another library; and publication uses the same
sample-file rule as verification, so a verified film titled "Samples" is
publishable. Language and quality requirements are unchanged.
